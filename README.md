# 小蟒同学（xiaomang）

面向 Windows 的桌面效率工具：截图、录屏、贴边便签、待办、剪切板、收藏夹、本地日记与输入辅助。

## 直接使用

**下载本仓库源码后，双击根目录的 `启动小蟒.cmd`。** 首次联网下载匹配的使用包，通过 SHA256 校验后解压运行；后续复用本地程序，不需要安装开发环境。

也可以从 [Releases](https://github.com/zhanglegezhang/xiaomang/releases) 下载使用包，完整解压后运行 `xiaomang.exe`。

- 系统要求：Windows 11 22H2 及以上，x64。使用包自带 .NET 9.0.21，不需要另行安装 .NET。部分功能需要 WebView2，缺少时按程序提示安装。
- 启动入口首次下载约 115.3 MB（110 MiB），解压约 281.9 MB，保存在 `%LOCALAPPDATA%\XiaomangSourceLauncher\v3.9-20261026`。个人记录不会写入源码仓库。
- 保留旧数据升级时，优先使用旧程序“关于 → 检查更新”。若3.3因.NET提示无法打开，请先退出相关提示，下载3.9使用包完整解压并覆盖原程序目录，保留个人数据目录，不要卸载或删除旧数据。仓库启动入口按版本使用独立目录，不会自动迁移旧目录中的记录；首次切换本版本会重新下载，后续复用。
- 下载或校验失败不执行程序，可重新运行重试。需要代理时，在 PowerShell 中运行 `./scripts/Start-Xiaomang.ps1 -Proxy http://你的代理地址:端口`。
- 首次使用密码向发布者索取；功能思维导图、版本日志和检查更新在程序“关于”中。
- 录屏、语音模型、文本输入法和中英 OCR 通过“全局设置 → 注册”按需下载；入口不会自动注册这些组件。

## 继续开发

从 Code → Download ZIP 下载，或克隆本仓库。按 [开发指南](docs/DEVELOPMENT.md) 准备环境后，使用统一构建入口：

```powershell
./scripts/Build.ps1 -Component All -Test
```

**“启动小蟒”运行的是已发布程序，不会自动编译修改后的源码。** 开发修改应编译后运行 `artifacts/Desktop/xiaomang.exe`；开发构建所需运行环境和外部工具边界见开发指南。

| 目录 | 内容 |
| --- | --- |
| `src/Desktop` | 主程序、截图、便签、系统集成与原生注册组件 |
| `src/Diary` | 本地日记界面、编辑器、存储和检索 |
| `src/InputMethod` | 文本输入法引擎、后台、候选窗与设置 |
| `src/FileFavoritesMenu` | Windows 收藏菜单 |
| `resources` | 构建必需的图标和培训资源 |
| `scripts` | 下载启动与统一构建入口 |
| `docs` | 开发和验证说明 |
| `licenses` | 第三方许可材料 |

## 主要功能

- 截图、区域截图、录屏、贴图与拾色。
- 贴边便签：待办、剪切板、收藏夹、工具和日记。
- 本地日记：树形目录、TXT/Markdown、检索替换、图片与表格、自动保存、回收站、导入导出和备份。
- 全局语音输入、文本输入法和文本对比。

## 版本与对应源码

本次发布 3.9：贴片支持闲置缩窄与手动收起，保留四种主题；精简截图、OCR、录屏及通知设置，录屏明确区分完成与放弃。

当前启动入口固定使用 [小蟒 3.9 / 2026-10-26](https://github.com/zhanglegezhang/xiaomang/releases/tag/v3.9-20261026)，不跟随 latest 自动更换版本。

- 使用包：`xiaomang3.9_2026-10-26_usage.zip`
- SHA256：`4D41AC9F874027DCC466553EA5F1F44F2DA67CFAB2D8011333602541B412CEF0`
- 对应源码标签：`v3.9-20261026`。桌面程序从本标签源码重新构建，包含截至 2026-10-26 已验证的修改；本地日记沿用上一版本已验证程序，附对应维护源码。
- 注册页统一管理 OCR、录屏及输入组件，提供组件移除入口；四处更多操作菜单统一样式。
- OCR 独立窗口不锁住主菜单、贴片和托盘，支持原文与译文复制及中英识别切换。
- 百度翻译 API 可选配置，提供前往认证、清空本机认证和密钥遮罩；凭据仅当前用户本机加密保存，不随包分发。未配置时继续使用网页翻译。
- 修复鼠标右键收藏注册失败：可修复旧目录失效的菜单入口，失败时显示具体步骤、错误码、路径并保存诊断日志。
- 更新准备显示文件检查进度；持续有进展时继续等待，停滞时安全自动重试一次并复用下载包。
- 录屏支持电脑声音与麦克风混音，完善设备选择、暂停和设备中断处理。
- 中英 OCR 按需下载本地识别组件，空闲 60 秒后退出识别进程，异常时回退 Windows OCR。
- OCR 窗口先显示再识别，记住大小和位置；常用文件采集异常后自动恢复。
- 截图区分十字与方向缩放光标，选区边缘支持连续拖拽和悬停提示。
- 新用户录屏默认同时录制电脑声音与麦克风，已有用户设置优先。
