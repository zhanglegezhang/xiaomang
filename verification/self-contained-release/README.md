# 自带运行环境与旧版升级验证

- `Check-Gates.ps1`：验证新发布目录能通过检查，并拒绝3.3依赖系统框架的配置、缺失运行库、混合框架版本及错误入口架构。参数 `Published` 指向未重命名的自带运行环境发布输出；`BadRelease` 指向历史3.3目录；`Output` 使用新的测试目录。
- `Test-Startup.ps1`：使用隔离测试副本，设置空 .NET 搜索根目录，记录真实主程序完成数据加载的回执和本地运行库模块。需要当前Windows用户已完成首次使用验证；不复制授权文件。
- `Test-Upgrade.ps1`：用历史3.2、3.3程序各自内嵌的更新脚本，将干净的新使用包目录安装到合成记录副本，验证记录和设置保留。关闭、恢复 `DailyEntry` 指定的程序，运行前保存工作。旧3.3在启动前可用 `OldFrameworkRoot` 临时链接便携.NET的shared目录；更新前移除链接。`Versions` 可选择单个旧版本；旧程序二进制和历史包不修改。
- `Test-ReleaseCompatibility.ps1`：每个旧版本用独立PowerShell进程加载其真实更新器，核对新包解压哈希；提供 `ReleaseJson` 时也核对版本、下载信息及SHA256解析。

所有测试使用合成数据。真实更新助手的本地安装验证不等于通过远程检查更新按钮下载未发布版本。空搜索目录与本地模块检查也不等于在干净新电脑、虚拟机或Windows Sandbox中完成验收。
