# 小蟒系统语音输入组件（开发验证中）

用户已确认首次安装和注册独立 TSF 组件。它接收小蟒已有识别器的整段假设，在目标应用中更新 TSF composition；松开 Ctrl＋Alt 后提交最后一次识别结果。不复制语音模型，不修改青简输入法。主程序仍采用解压使用方式，组件首次安装需要 Windows 管理员授权。

## 构建

在项目根目录使用 PowerShell 执行：

```powershell
& tools/ShareX/source/ShareX-21.0.0/VoiceInput/Build.ps1
& tools/dotnet9/dotnet.exe build tools/ShareX/source/ShareX-21.0.0/ShareX/ShareX.csproj -c Release -r win-x64 --no-restore
```

Build.ps1 默认使用 tools/native-toolchain/llvm-mingw-20261006-ucrt-x86_64，可用 -Toolchain 指定工具链目录。编译器只用于开发，不随主程序发布。x64 安装器包含 requireAdministrator 清单；同时构建 x64 和 x86 组件以适配不同宿主位数。许可证保存在 Licenses，并复制至 bin/Licenses。

## 安装与卸载

保持 bin 下的 x86_64、i686 和 Licenses 目录完整。从原位置运行 bin/VoiceInputSetup.exe，默认安装；显式传入 install、repair 或 uninstall 可执行注册、强制修复、卸载。repair 会在文件相同时重新执行两个架构的注册并检查结果。安装路径固定为 Program Files/XiaomangVoiceInput/0.1.0，不移动主程序或模型。

安装器调用两个架构的注册助手，将本组件注册为 TSF speech 服务。注册失败会尝试撤回；诊断在对应架构的 registration.log。卸载撤销本组件注册，已被宿主加载的 DLL 可能要等宿主退出才能删除。不要强制结束用户应用。

一次早期非管理员注册实验留下了本组件 CLSID 的 HKCU COM 项。正式安装器成功后只清除此组件自己的覆盖项，确保系统加载 Program Files 下的 DLL。CLSID 为 {7FD8708D-A55C-492D-918F-1802DC259B3A}，profile 为 {96A307E7-E071-429B-A384-D9485884515F}。

## 输出与边界

- 完整假设更新组件自己持有的 composition，允许修正之前识别的词；提交成功时不修改剪贴板、不额外提示。
- IPC 使用按用户隔离的本地命名管道，按目标进程、会话、序号确认结果；命令有效期两秒，文本上限 4095 个 UTF-16 code units。
- 拒绝密码、只读输入、已有选中文字及管理员应用。焦点变化后不向新输入框续写，不删除周围原有文本。
- 不支持的输入上下文或输出失败仍将最终识别文本复制至剪贴板，并提示检查输入框后粘贴。
- Ctrl＋Alt、60 秒限制、现有模型与识别分段策略保持原有行为。
