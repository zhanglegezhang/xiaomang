01截图与标注

框选、标注、保存
  • 入口 · 默认 Ctrl + 1；也可在快捷键页配置。
  • 框选屏幕后，可加箭头、文字、序号、高亮或遮挡，再复制、保存、置顶。
  • 边缘整条都能拖：方向箭头提示缩放，橙色边框提示已抓到热区；小选区仍留出中间移动位置。
长截图与截图转待办
  • 入口 · 截图工具栏 → 长截图／添加待办。
  • 长截图捕捉超出一屏的内容；添加待办把截图文字带进待办列表。
  • 截图置顶后可拖到旁边对照，双击在放大与缩小间切换。

02识字与翻译

截图文字识别（OCR）
  • 入口 · 截图工具栏 → 识别文字；或配置 OCR 快捷键。
  • 在“中+英／中／EN”间循环切换；识别结果可编辑、复制，原文与译文左右对照。
  • 独立识别窗口记住尺寸，打开时在当前屏幕居中；查看结果时仍能使用主菜单、贴片和托盘。
网页翻译与个人 API
  • 入口 · OCR 窗口 → 翻译／复制译文；API 配置：全局设置 → 注册 → OCR 识别组件 → 更多操作。
  • 未配置时使用网页翻译；配置个人百度翻译 API 后使用个人额度，支持中英文译文。
  • 翻译失败可重试或改用网页；API 凭据仅本机加密保存，不随程序包分发。翻译需要联网。

03录屏与声音

记录屏幕和讲解
  • 入口 · 默认 Ctrl + 2；音频在全局设置 → 屏幕录制中选择。
  • 录屏支持电脑声音＋麦克风同步混音，也可暂停、继续或停止。
  • 新用户默认双路声音，已有用户保留原设置；声音来自每段录制开始时的系统默认设备。戴耳机可减少回声。
组件与视频转换
  • 入口 · 全局设置 → 注册 → 录屏组件；4工具 → 视频转 GIF。
  • 录屏、视频转 GIF 和视频缩略图共用 FFmpeg；缺少时按需下载。
  • 电脑没有播放声音时，时间轴仍继续；设备采集中断会提示。GIF 本身不含声音。

04贴边便签与待办

五个贴片，一个随手入口
  • 入口 · 桌面贴边浮标 → 1待办、2剪切板、3收藏夹、4工具、5日记。
  • 随手记录事项、设置提醒，完成后勾选；拖动标题调整位置，双击机器人打开主菜单。
  • 长按浮标录音，松开生成带音频的待办；转写失败仍留录音。右键浮标可直接打开全局搜索。
剪切板与文字收藏
  • 入口 · 2剪切板保存复制过的文本；3收藏夹保存常用文字。
  • 记录可搜索、复制和整理；双击剪切板记录，复制回系统剪贴板后即可粘贴。
  • 便签底边有透明的加宽拖拽区域，外观保持轻巧，也更容易拉长窗口。

05文件收藏与常用推荐

把文件留在手边
  • 入口 · 资源管理器右键 → 添加到小蟒收藏夹；首次在全局设置 → 注册中启用。
  • 固定文件或文件夹后，从 3收藏夹直接打开；路径失效时可更改位置。
  • 取消固定只移除入口，不删除真实文件。多选添加汇总提示，不抢正在输入的焦点。
常用项目自动浮上来
  • 入口 · 3收藏夹 → 常用文件与目录。
  • 根据实际访问线索推荐常用项目，可固定或选择“不再推荐”。
  • 只看使用线索，不扫描整个硬盘；已经固定的项目不重复推荐。

06全局搜索

一次找回多处内容
  • 入口 · 右键托盘图标或贴边浮标 → 全局搜索。
  • 统一查待办、文字收藏、本地日记及固定文件路径；剪切板历史可按需纳入。
  • 打开结果后搜索窗口不关闭，关键词、选中项和滚动位置留在原处；窗口宽高也会记住。
  • 最多展示 300 条；不扫描全盘，也不搜索外部收藏文件的正文。

07本地日记

把零散想法写成文档
  • 入口 · 5日记 → 本地日记。
  • 树形目录管理 TXT、Markdown；多页签编辑，支持标题、列表、代码、链接、图片和自定义表格。
  • 编辑后约 5 秒自动保存，Ctrl + S 仍可手动保存；图片粘贴到 Markdown 后作为本地附件保存。
更顺手的整理和查找
  • 入口 · 目录／文件右键 → 重命名、移动到、设置颜色或导出日记。
  • 展开会打开全部子目录；收起只关闭当前目录，保留子目录展开状态。移动仅限日记内部，颜色只应用于图标。
  • 点击左侧主页图标可从搜索返回日记；2—16 个纯汉字支持按顺序隔字匹配。
备份与找回
  • 入口 · 日记左侧栏底部 → 导入日记、备份、导入备份。
  • 支持 .md、.txt 导入；误删内容可在回收站找回，文件右键底部可导出。
  • 日记备份是文件夹；.xmbackup 是全局个人数据备份，两者使用各自的导入入口。

08语音与文本输入

按住说话，松开完成
  • 入口 · 在目标软件输入框中按住 Ctrl + Alt。
  • 说话时文字逐步更新到当前输入框，松开后完成输入；机器人上的红色麦克风呼吸提示正在听。
  • 无法确认输入焦点时，结果保留到系统剪贴板，可手动粘贴；这类兜底文本不进入剪切板历史。
小蟒文本输入法
  • 入口 · 全局设置 → 注册准备组件；默认 Ctrl + Shift + J 切换。
  • 提供中英文输入，可调整候选字体、颜色与排列；与全局语音打字独立使用。
  • 文本输入法有独立后台，退出小蟒后仍能继续输入。

09桌面工具

临时写、快速画
  • 入口 · 4工具左列顶部：空白.txt → 画图 → 空白.md。
  • 临时文本自动保存，Markdown 可预览；画图适合简单草图，文本对比用于查看差异。
  • 临时编辑器把文件名、保存状态和“另存为”放在紧凑标题栏；之前的临时内容可从临时文件夹找回。
文件、图片与计算
  • 入口 · 4工具；屏幕拾色器默认 Ctrl + 3，窗口置顶默认 Ctrl + F10。
  • Everything 搜文件，7-Zip 管压缩包，拼图合并图片，计算器与数据处理工具处理日常任务。
  • 画图滚轮围绕鼠标位置缩放；窗口置顶适合边看边录入。
每日资讯与天气
  • 入口 · 4工具 → 国内资讯／国际资讯／天气；全局设置 → 每日资讯。
  • 资讯可切换国内、国际来源；天气与资讯更新需要联网。

10设置、数据与更新

按需要准备组件
  • 入口 · 全局设置 → 注册。
  • 集中下载、校验、修复录屏、语音、文本输入和 OCR 组件；更多操作中提供移除或撤销入口。
  • 已有有效组件会复用；中英 OCR 组件约 29 MiB，离线识别。移除 OCR 后回退 Windows 识别；移除组件保留个人数据。
习惯自己定，位置随时找
  • 入口 · 主菜单 → 全局设置／快捷键／便签文件夹／截图文件夹／临时文件夹。
  • 调整开机启动、语言、快捷键和截图通知；存储位置页可查看、打开各类数据目录。
  • 资讯、Markdown 预览与本地日记依赖 WebView2，缺少时按应用提示安装。
迁移个人数据
  • 入口 · 全局设置 → 常规 → 导出个人数据／导入个人数据。
  • 用 .xmbackup 迁移待办、收藏、日记、快捷键等；截图和录屏可选，待办录音随待办一起备份。
  • 缺少输入法组件时先恢复其他内容，输入法数据保留待处理；组件就绪后再点“恢复待处理输入法数据”。外部收藏文件本体不随入口自动打包。
查看变化，安全升级
  • 入口 · 关于 → 版本日志／检查更新；旧版也可使用通用升级工具。
  • 更新前备份实际数据，加载确认失败时回退原程序与数据；未安装输入法组件也可升级。
  • 版本日志和本页离线可看，检查与下载更新需要联网。启动入口统一为 xiaomang.exe。
