# 小蟒产品默认值

本目录为 2026-10-01 用户确认的当前偏好快照，两个 JSON 作为资源编译进 ShareX.dll。

- `ApplicationDefaults.json`：界面、快捷键以外的全局偏好、截图、录屏、通知、工具参数、窗口尺寸和分栏比例。
- `HotkeyDefaults.json`：四个快捷键及其任务参数。继承全局参数的标志保留。
- `../ProductDefaults.cs`：在配置对象构造后应用快照。旧配置随后反序列化，旧值优先。首次运行、恢复默认以及配置和备份均不可用时使用产品默认值。

不包含便签内容、剪贴板记录、收藏、历史、最近使用记录、API 密钥、代理凭据、自定义命令、外部程序、上传账户、文件监视目录或本机绝对路径。默认截图目录由程序根据安装目录生成；录制使用 gdigrab 屏幕源，不携带作者的摄像头或声卡名称。需要身份验证的服务由使用者自行配置。

保留窗口大小、分栏比例和字体颜色等偏好；窗口坐标、上次输入/输出文件及最近选取的图片不继承。窗口显示时根据当前屏幕限制尺寸。当前录屏延迟 3 秒、通知位置 BottomRight、自动清理备份和日志各保留 10 个文件。

快照不会随日常使用自动更新。只有用户明确要求更新产品默认值时，在开发目录运行 `tools/ShareX/export-product-defaults.ps1`。脚本只选择经过审核的偏好字段，写入前拒绝明显的本机路径、未审核的 URL 和邮箱；OCR 公共服务链接按完整网址白名单审核。新增字段必须先审核，不能改成复制整个用户配置。导出后编译并运行 `verification/product-defaults` 的检查。

默认值内嵌在程序中，发布时无需携带日常使用的 ApplicationConfig.json 或 HotkeysConfig.json。包含源码时必须保留本目录及 ProductDefaults.cs；公开联系方式仍由原产品资源保留。本次更改不创建发布包、不上传网盘。
