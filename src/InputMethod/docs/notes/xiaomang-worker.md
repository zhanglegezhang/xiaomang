## Windows 布局测试隔离（2026-10-09）

`tsf/src/com/key/layout.rs` 的测试不再调用 LoadKeyboardLayoutW：该 API 会加载会话布局，
`KLF_NOTELLSHELL` 不能保证隔离，之前测试残留过德语、美国英语国际键盘。
四项依赖指定布局或修改键盘状态的 OS 集成测试标记为 ignored，常规 Test 不执行。
只在可丢弃的 Windows 虚拟机里预装 US、German、US International，停止输入法后台后，
设置 `XIAOMANG_ISOLATED_LAYOUT_TESTS=1`，再单独运行 layout 测试的 `--ignored --test-threads=1`。
测试仅查询预装布局；缺失时失败，不自动安装。变体 HKL 根据系统 Layout Id 推导。
普通测试报告必须列出忽略数量，不把这四项记为本机验证通过。
本机残留清理脚本为项目根目录 `verification/input-exit/ClearTestKeyboardLayouts.ps1`：默认只读，
`-Apply` 仅移除获用户批准的德语和美国英语国际键盘，并保存前后清单；不重写语言列表，
不更改普通 US、微信或小蟒 TSF，API 成功仍需核验真实切换列表。

## 后台运行

通信预算：最多 128 条连接、512 个会话，每条连接最多 16 个会话；客户端帧上限 256 KiB，
每秒最多 1024 个请求。读取首帧和不完整帧、写入及等待路由回复均设 5 秒截止时间。
已认证的空闲连接每 600 秒唤醒检查并继续等待，兼容长期失焦的旧 TSF 客户端。
后台通过系统查询管道客户端 PID、会话线程所属 PID；会话绑定连接代次，
同进程重连可转移归属，旧连接断开只回收仍属于自己的会话。消息格式与已安装 TSF 保持兼容。
异常消息关闭所属连接；不会关闭其他应用的正常会话。普通键入不增加额外等待定时器。

TSF 只转发事件，不持有 Engine，不自行启动后台。主程序以 `--resident --stop-event` 启动引擎，
停止事件按当前用户 SID 和 Windows session 命名。后台持有事件句柄，主程序退出只释放自己的监测与句柄，
不发送停止，不改变当前输入法；重新打开时按完整程序路径和会话找到后台，复用事件和进程。
模型与管道就绪通过连接和 GetNamedPipeServerProcessId 核对实际后台 PID。
启动前用当前会话管道名生成的互斥体阻止第二份引擎加载，管道继续使用 FIRST_PIPE_INSTANCE。
明确重试或撤销注册会发停止事件，Router 工人循环落盘；最多等四秒后终止经路径和会话核对的后台。
Windows 重启/注销结束后台，不新增服务、登录启动项或计划任务；若主程序自身开机启动，则间接启动引擎。
主程序运行时连续五次启动失败停止自动重试；设置页可显式重试。主程序退出后没有监护进程，
后台崩溃需再打开主程序恢复。保留 `--parent-pid` 的旧生命周期用于兼容与测试。
旧暂停标记仅在后台就绪时恢复；主程序不再生成暂停标记。
TSF 使用 overlapped 管道 I/O，700ms 超时后取消并等取消完成，释放缓冲区。
断线时按键放行，不吞键。表情候选在 Engine 插入步骤之前开关控制，
保留表情表，通用配置缺省关闭。设置程序和后台均取消官方更新入口/检查。

尚未注册时小蟒不启动后台。注册组件用原生安装器，复制 DLL 到 Program Files
受保护目录，分别登记 x64/x86，不将可写 portable 路径写入系统 COM 注册。
安装器仅处理本分支身份；原青简和原语音 TSF 不变。

固定 Ctrl + Shift + J 由小蟒主程序登记，外部输入窗口通过 TSF 会话选择与输入语言请求切换，不抢焦点。
TSF 单击判定记录未配置为切换键的修饰键，避免系统截走 J 后误触 Shift 中英切换。
该补丁的系统组件目录为 `0.1.4-hotkey1`，与旧 `0.1.4` 并行安装，注册身份和个人数据不变；
避免覆盖被宿主加载的旧 DLL。升级失败不撤销已有可用注册；已有宿主重新打开后加载新组件。
撤销注册时优先新目录；尚未升级的旧机器回退旧目录进行撤销。

设置窗口使用独立的 `Local\XiaomangInputSettings` 互斥体和窗口标题，
不被原青简已打开的设置窗口阻挡。注册完成后验证两种架构的 COM、
语言 profile 和键盘类别；撤销后检查本分支注册项已清除才删除组件。
