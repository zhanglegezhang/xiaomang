# 小蟒输入法

这是基于青简 0.1.4 的固定维护分支，与原青简分别安装。

输入法使用青蓝色背景的小机器人图标，在 Windows 输入法列表和输入法设置窗口中显示。

在小蟒的「输入法 → 小蟒输入法」点击「注册 / 修复」，授权注册系统组件。
然后在 Windows 中文语言选项中添加「小蟒输入法」，按 Win + 空格切换。
只需首次注册。打开小蟒会启动或连接同一个输入法后台；退出小蟒后后台继续运行，
输入法仍可使用，不切换或禁用当前输入法。重复打开小蟒不会重复加载引擎。
Windows 重启或注销会结束后台；后台没有独立的开机启动项，再次打开小蟒才恢复。
如果小蟒本身设为开机启动，也会启动输入法后台。
系统重启后输入法名称仍在列表里，在首次打开小蟒之前不会提供候选词。
「重试后台」明确停止并重启引擎，「撤销注册」停止后台并撤销系统注册，保留设置和学习数据。
后台意外退出时，小蟒仍运行则会自动重试；小蟒已退出则需重新打开小蟒恢复。
旧版本由小蟒保存的暂停标记会在后台就绪后恢复，不主动切换输入法，不恢复用户自行禁用的条目。
普通应用关闭再打开后可加载更新后的系统组件。

「输入法设置 → 通用」可以调整每页候选数（1–9）。
「候选窗口」可以设置外观、字体、横竖排和「显示表情候选」。
表情默认关闭，普通文字候选填满候选页；重新开启即可恢复表情。
配置保存后后台约一秒自动加载，不需要重启小蟒。

「快捷键」的初始默认值：翻页键 `-` / `=`，表达式模式 `v`，问字模式 `u`，
「敲 ? 也进入问字」关闭；第一、第二条译词分别用 `Ctrl`、`Ctrl + Shift` 加候选序号上屏，
`Shift` 加候选序号删除候选，`Ctrl + Alt + T` 翻译选中文字（需开启云服务）。
已有设置保留，以上选项仍可自行调整。

此维护版仅保留中英释义：中文候选旁显示英文、英文候选旁显示中文。
「通用 → 学习语言」可选择英语或不显示译文，不再提供日语、西班牙语选项。
旧设置选中过已移除的语言时，会改为英语并保存，同时更新旧配置说明。
其他偏好及个人学习数据保留。

小蟒的 Ctrl + Alt 语音输入保持独立，不依赖切换到这个键盘输入法。
配置和学习词库在 `%APPDATA%\XiaomangInputMethod`，原青简目录不变。
撤销注册保留学习数据；此分支只随小蟒更新，不自动检查青简官方新版。

未签名的候选窗口在部分系统/UWP 界面可能被遮挡。
此版本不承诺在管理员窗口、登录界面和安全桌面中工作。
